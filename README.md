# Loan Sanction, Disbursement & Recovery Analytics Dashboard

This project presents an end-to-end **Power BI dashboard** designed to analyze the complete loan lifecycle — from loan application to sanction, disbursement, and recovery.  
The goal of this project is to transform raw loan data into **clear, actionable business insights** through effective data modeling and visualization.

---

## 📌 Project Overview

Financial institutions handle large volumes of loan data across multiple branches, products, and customer segments.  
This dashboard helps stakeholders understand:
- How much loan amount is applied, sanctioned, disbursed, and recovered
- Which branches, products, and channels perform better
- Customer segments contributing to higher loan values
- Trends and efficiency across the loan lifecycle

---

## 🎯 Objectives

- Analyze loan performance at different stages of the loan process  
- Track key performance indicators (KPIs) related to loan conversion and recovery  
- Enable branch-wise and customer-wise performance analysis  
- Provide interactive, business-ready insights for decision-making  

---

## 🛠 Tools & Technologies

- **Power BI**
- **DAX**
- **Data Modeling (Star Schema)**
- **Data Visualization & Dashboarding**
- **Business Analytics**

---

## 📊 Key KPIs

- Total Applied Loan Amount  
- Total Sanctioned Amount  
- Total Disbursed Amount  
- Total Recovered Amount  
- Sanction Rate (%)  
- Disbursement Rate (%)  
- Recovery Rate (%)  

---

## 📈 Dashboard Features

- Loan funnel analysis (Applied → Sanctioned → Disbursed → Recovered)
- Branch-wise and channel-wise performance comparison
- Customer segmentation analysis (Age group, occupation, product type)
- Trend analysis over time (monthly/yearly)
- Key Influencers and Decomposition Tree visuals
- Interactive filters and slicers for dynamic exploration

---

## 📂 Dataset Information

The project uses structured datasets related to:
- Customers

- Recovery Information
